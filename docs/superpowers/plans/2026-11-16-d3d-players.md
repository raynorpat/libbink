# Windows D3D9 / D3D11 Players Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two raw-Win32 players, `bink_d3d9_player` and
`bink_d3d11_player`, with the same two shaders as `bink_sdlgl_player`,
built on Windows and cross-compilable with mingw here.

**Architecture:** The playback module splits into a backend-neutral core
(publish, seek, shutdown) and per-backend device files (SDL, Win32
`waveOut`). A shared Win32 `main` owns the window, clock, keys and audio
and calls a small renderer interface implemented once for D3D9 and once
for D3D11.

**Tech Stack:** C99, Win32, Direct3D 9 and 11, `D3DCompile` from
`d3dcompiler`, `waveOut`, CMake, mingw-w64.

**Spec:** `docs/superpowers/specs/2026-11-16-d3d-players-design.md`

## Global Constraints

- No new dependency beyond the Windows SDK and `bink_mix`.
- No change to `src/bink.h` or decoder behaviour.
- Every device, shader and texture failure reports and exits non-zero.
- Shaders compile at run time with `D3DCompile`; no D3DX.
- The SDL players must keep building and behaving identically.

## Review Focus

- A plane whose stride exceeds its width (32-aligned strides): the
  upload must not read past the plane or shear the image.
- A 4:2:0 plane whose width or height is odd (17x9 exists in the suite).
- The first frame and a keyframe: motion is all zero, so the
  interpolation must crossfade, not divide by zero.
- A seek while interpolating: the pair must be dropped, not blended
  across.
- Device creation on a machine without a usable GPU path: report, do not
  crash.

### Task 2: Win32 audio backend

**Files:**
- Create: `src/tools/bink_playback_win32.c`

**Interfaces:**
- Same eight functions as the SDL backend, over `waveOut`.

- [ ] **Step 1: Implement the device**

A private context with `HWAVEOUT`, a fixed ring of eight `WAVEHDR`s each
with its own buffer, and the next index. `queue` copies the caller's
bytes into a ready header and writes it; `queued` sums the bytes of
headers without `WHDR_DONE`, reclaiming done headers first. `open`
calls `waveOutOpen(..., CALLBACK_NULL)` with the requested rate, 16-bit
and channel count; `set_paused` uses `waveOutPause`/`waveOutRestart`;
`close` resets, unprepares and closes. `audio_subsystem` returns 0.

- [ ] **Step 2: Compile-check it**

Run: `x86_64-w64-mingw32-gcc -std=c99 -Wall -Wextra -c src/tools/bink_playback_win32.c -Isrc -o /tmp/p.o`
Expected: no warnings.

- [ ] **Step 3: Commit**

```bash
git add src/tools/bink_playback_win32.c
git commit -m "tools: add a waveOut playback backend"
```

### Task 3: Renderer interface and D3D11

**Files:**
- Create: `src/tools/bink_d3d_renderer.h`, `src/tools/bink_d3d11_renderer.c`

**Interfaces:**
- Produces:
  ```c
  typedef struct BinkD3DRenderer BinkD3DRenderer;
  typedef struct {
      int interp;          /* 0 presentation, 1 interpolation */
      int have_next;
      float t;
      unsigned long blocks_w, blocks_h;
  } BinkD3DDraw;
  BinkD3DRenderer *bink_d3d11_renderer_create(void *hwnd, unsigned long w,
                                              unsigned long h);
  int bink_d3d_renderer_upload(BinkD3DRenderer *r, bink object, int slot);
  int bink_d3d_renderer_upload_motion(BinkD3DRenderer *r, bink object);
  int bink_d3d_renderer_draw(BinkD3DRenderer *r, const BinkD3DDraw *draw);
  void bink_d3d_renderer_destroy(BinkD3DRenderer *r);
  ```

- [ ] **Step 1: Header**

Declare the type, the draw struct, and the four entry points above. The
HWND is a `void *` so the header does not need `windows.h`.

- [ ] **Step 2: Device and swap chain**

`D3D11CreateDevice` (hardware, feature level 11_0, falling back to
10_1/10_0) and `CreateSwapChain` on the HWND, `R8G8B8A8_UNORM`, windowed,
one back buffer; create the RTV.

- [ ] **Step 3: Shaders and constants**

Compile `vs_4_0`, `ps_4_0` presentation and `ps_4_0` interpolation from
strings in the file with `D3DCompile` (report the compiler's message and
fail). One constant buffer holds three matrix rows, the offset, luma
size and `t`, and the block counts. A quad of six vertices, position
only, uv derived in the vertex shader with the y flipped.

- [ ] **Step 4: Textures and upload**

Two slots of three `R8_UNORM` planes plus one `RG8_UNORM` motion
texture. `UpdateSubresource` directly when `stride == width`, otherwise
stage rows into a scratch buffer first. The motion texture packs
`mv + 128` into R and G.

- [ ] **Step 5: Draw**

Bind the back buffer, set the viewport, clear, choose the presentation
or interpolation program, bind SRVs (linear sampler for planes, point
for motion), update constants, draw six vertices, present.

- [ ] **Step 6: Compile-check**

Run: `x86_64-w64-mingw32-gcc -std=c99 -Wall -Wextra -c src/tools/bink_d3d11_renderer.c -Isrc -o /tmp/d11.o`
Expected: no warnings.

- [ ] **Step 7: Commit**

```bash
git add src/tools/bink_d3d_renderer.h src/tools/bink_d3d11_renderer.c
git commit -m "tools: add a D3D11 renderer"
```

### Task 4: D3D9 renderer, player, and build

**Files:**
- Create: `src/tools/bink_d3d9_renderer.c`, `src/tools/bink_win32_player.c`,
  `cmake/mingw-w64.cmake`
- Modify: `CMakeLists.txt`

- [ ] **Step 1: D3D9 renderer**

`Direct3DCreate9`, `CreateDevice` with `D3DDEVTYPE_HAL` and hardware
vertex processing (software fallback), windowed swap chain. Planes as
`D3DFMT_L8` and motion as `D3DFMT_A8L8`, both `D3DPOOL_MANAGED`
(`LockRect`, copy rows). `ps_3_0` shaders; a pre-transformed quad with
`D3DFVF_XYZRHW | D3DFVF_TEX1` and no vertex shader. Linear filtering for
planes, point for motion.

- [ ] **Step 2: Shared player**

`bink_win32_player.c`: register a window class, create the window at the
video size, open the file, create the renderer (`BINK_D3D11` selects
which), publish audio, and run the same loop as the GL player — pair,
clock, `t`, advance, keys (`Esc`/`Q`/`Space`/`Left`/`Right`/`M`), seek
resets the pair. `BINK_D3D_TEST_FRAMES` and `BINK_D3D_SHADER` mirror the
GL hooks.

- [ ] **Step 3: Toolchain and targets**

Add `cmake/mingw-w64.cmake` (system name Windows, the mingw compiler
triple). Under `if(WIN32)`, add both executables with the shared sources
and `d3d9`/`d3d11`/`dxguid`/`d3dcompiler`/`winmm`.

- [ ] **Step 4: Cross-compile**

Run: `cmake -S . -B build-win -DCMAKE_TOOLCHAIN_FILE=cmake/mingw-w64.cmake -DBINK_BUILD_TOOLS=ON -DBINK_BUILD_TESTS=OFF && cmake --build build-win`
Expected: `bink_d3d9_player.exe` and `bink_d3d11_player.exe` link with
no warnings from our code.

- [ ] **Step 5: Verify the SDL side is untouched**

Run: `cmake --build build && ctest --test-dir build`
Expected: 100%.

- [ ] **Step 6: Commit**

```bash
git add src/tools/bink_d3d9_renderer.c src/tools/bink_win32_player.c \
        cmake/mingw-w64.cmake CMakeLists.txt
git commit -m "tools: add D3D9 and D3D11 players for Windows"
```
