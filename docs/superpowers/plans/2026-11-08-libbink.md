# libbink Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a dependency-free C99 Bink 1 video decoder with a libsmacker-style API, plus SDL2/SDL3 playback and a headless frame dumper.

**Architecture:** Port FFmpeg's LGPL Bink 1 container, bitstream, and video algorithms into a small library split into container/API, bitstream/Huffman, bundle/video decode, and DSP files. Decode to padded YUV420p planes; expose those plus a lazy RGB24 buffer. Verify against YUV frames captured from VLC.

**Tech Stack:** C99, CMake 3.16+, SDL2 or SDL3, VLC (reference capture only), Python 3 (reference checksum generation).

**Spec:** `docs/superpowers/specs/2026-11-08-libbink-design.md`

## Global Constraints

- C99, standard library only for the library. No FFmpeg/libav runtime dependency.
- LGPL-2.1-or-later. Ported files retain FFmpeg copyright headers; README and docs credit FFmpeg.
- Support `BIKf`, `BIKg`, `BIKh`, `BIKi`. Reject `BIKb`, `BIKk`, and `KB2*` with a clear diagnostic.
- Public names and constants exactly as in the spec: `bink`, `bink_*`, `BINK_*`.
- Decoding is disabled until `bink_enable_video(object, 1)`.
- Pointers returned by `bink_get_*` are library-owned and valid until `bink_close`; contents change on the next decoded frame.
- `-Wall -Wextra` clean (MSVC `/W3`).
- Test media lives outside the repo. Tests read `BINK_TEST_MEDIA`, defaulting to `$HOME/Downloads`, and return 77 (skip) when it is absent.
- Every commit builds and passes its task's tests.
- The repository is already initialized with the approved design committed.
- FFmpeg reference sources: use the copies already fetched into the session temp directory, or re-fetch `libavcodec/bink.c`, `libavcodec/binkdsp.c`, and `libavcodec/binkdata.h` from `https://raw.githubusercontent.com/FFmpeg/FFmpeg/master/`.

## Review Focus

1. Truncated or corrupt files: `bink_open_*` returns NULL or `bink_next` returns `BINK_ERROR`; never crashes or reads out of bounds.
2. 1920x1080 and 1440x1080 chroma padding: the last four internal chroma rows must not overflow or corrupt the visible 540 rows.
3. `BIKi` plane size prefixes and interleaved audio chunks: audio sizes are skipped exactly and video starts at the right byte.
4. Seeking when frame 0 is the only keyframe: `bink_seek_keyframe` resets state and decodes from 0 without stale motion pixels.
5. Disk versus memory mode: both produce identical planes and hashes.

```c
#define LIBBINK_TEST_COMMON_H

#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define CHECK(cond) do { \
    if (!(cond)) { \
        fprintf(stderr, "FAIL %s:%d: %s\n", __FILE__, __LINE__, #cond); \
        return 1; \
    } \
} while (0)

#define FNV_OFFSET UINT64_C(14695981039346656037)
#define FNV_PRIME  UINT64_C(1099511628211)

static inline uint64_t fnv1a(const void *data, size_t size)
{
    const unsigned char *p = (const unsigned char *)data;
    uint64_t h = FNV_OFFSET;
    size_t i;

    for (i = 0; i < size; i++) {
        h ^= p[i];
        h *= FNV_PRIME;
    }
    return h;
}

static inline uint64_t fnv1a_rows(const unsigned char *p, int width,
                                  int height, int stride)
{
    uint64_t h = FNV_OFFSET;
    int x, y;

    for (y = 0; y < height; y++) {
        for (x = 0; x < width; x++) {
            h ^= p[x];
            h *= FNV_PRIME;
        }
        p += stride;
    }
    return h;
}

static inline const char *test_media_dir(void)
{
    return getenv("BINK_TEST_MEDIA");
}

#endif
```

- [ ] **Step 1: Write the checksum generator**

`tests/gen_reference.py` parses YUV4MPEG2 files. It reads the header line `YUV4MPEG2 W<w> H<h> F<num>:<den> ...`, then each `FRAME\n` header followed by `w*h` Y bytes, `((w+1)//2)*((h+1)//2)` U bytes, and the same number of V bytes.

- [ ] **Step 3: Implement header parsing**

`src/bink_internal.h` defines `struct bink_t` and the audio descriptor array. `src/bink.c` implements:

- `bink_open_memory`: copy the buffer, parse the header, return the handle.
- `bink_open_filepointer`: disk mode keeps the `FILE *`; memory mode reads the whole file, closes the stream, and delegates to `bink_open_memory`.
- `bink_open_file`: open with `fopen(filename, "rb")`, delegate, close on failure.
- Header parsing:
  - Reject sizes below 44 bytes.
  - Accept signatures `BIKf`, `BIKg`, `BIKh`, `BIKi`.
  - Reject `BIKb`, `BIKk`, `KB2*` with `libbink:: unsupported Bink version` on stderr.
  - Read file size (field + 8), frame count, largest frame size, width, height, fps numerator/denominator, flags, and audio track count.
  - Validate frame count <= 1000000, width/height within 7680x4800, fps numerator and denominator nonzero, audio tracks <= 7.
  - Audio descriptors: skip `4 * tracks` max-size words, then read `rate` (u16), `flags` (u16), and store channels (`flags & 0x2000 ? 2 : 1`), bitdepth 16, rate. Skip `4 * tracks` track IDs.
  - Read the frame offset table: `frame_count` little-endian u32 entries. Store `offset = entry & ~1`. Frame 0 is a keyframe; frame `i >= 1` is a keyframe when `entry[i] & 1`.
  - Compute each frame size from the next offset, and the last frame from the file size. Validate offsets are monotonic, within the file, and at least the header end.
- `bink_info_all/video/audio` fill the requested outputs; return -1 for a NULL handle.

- `bink_video_init` computes luma block counts `bw = (width + 7) >> 3`, `bh = (height + 7) >> 3`; chroma block counts `cbw = (width + 15) >> 4`, `cbh = (height + 15) >> 4`.
